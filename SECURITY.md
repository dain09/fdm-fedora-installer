## Reporting a Vulnerability

We take the security and integrity of this project seriously.

If you discover a security issue or vulnerability (such as compromised download links, permission escalations, or script integrity issues), please do not disclose it publicly via GitHub Issues.

### How to Report:
* Please report vulnerabilities directly to the maintainer via email: **iabdollah40@gmail.com**
* Include relevant details (description, steps to reproduce, impact).
* We will acknowledge receipt of your report promptly within 48 hours and work on a resolution.

Thank you for helping keep the open-source community secure!
